# Tb_acloud

In this repository we will develop a complex test for a LLM SOTA model

The selected task studies interacting topological charge pumping. Start with
[instructions.md](instructions.md); the numerical specification is in
[task.md](task.md).

Download the candidate files as a [ZIP](dist/Tb_acloud-candidate.zip) or
[tar.gz](dist/Tb_acloud-candidate.tar.gz). Each archive contains the prompt,
specification, fixed inputs, requirements, result schema, format documentation,
and public validator, preserving the expected directory structure.

Reference answers, calibration, and evaluation tools are documented in
[author_only/README.md](author_only/README.md) and are excluded from the candidate
archives.
